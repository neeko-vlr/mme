Tema 4: Introducción a los Sistemas Operativos

1 Unidades de almacenamiento

  • • Unidad física: Es el dispositivo de hardware real que utilizamos para guardar información y programas (por ejemplo: un disco duro HDD, un CD-ROM o una disquetera FDD).
  • • Unidad lógica: Es la representación virtual que hace el sistema operativo de cada una de esas unidades físicas para poder gestionarlas.
  • • Asignación de letras (en Windows/DOS):
    A: y B: Reservadas históricamente para la primera y segunda unidad de disquete.
    C: y D: C: para el disco duro principal. D: para el 2º disco duro, partición o lector CD-ROM.
    E: en adelante Para siguientes discos duros, unidades ópticas o particiones adicionales.

2 Organización y Estructura del Disco Duro

Un disco (HDD, FDD) es un soporte electromecánico de almacenamiento no volátil (no pierde datos al apagarlo) que posee dos estructuras:

Estructura Física (De fábrica)

Viene definida en el proceso de fabricación:

  • • Caras (Heads): Cada uno de los dos lados de un plato del disco.
  • • Pistas (Tracks): Círculos concéntricos en los que se divide cada cara. Su número determina la capacidad.
  • • Cilindros: Conjunto de pistas con el mismo número en todos los platos apilados (se usa más este término que pista).
  • • Sectores: Cada una de las divisiones o "porciones" en las que se corta una pista.
  • • Peine y Cabezas: Brazo mecánico que mueve las cabezas de lectura/escritura sobre las caras.
Estructura Lógica (Al formatear)

La crea el usuario cuando da formato al disco:

  • • Cluster (unidad de asignación): Conjunto contiguo de sectores. Es la unidad mínima de almacenamiento que se lee o escribe.
  • • Sector de arranque (Boot): Situado en el sector 0. Contiene el cargador del SO y la tabla BPB (parámetros físicos).
  • • Tabla FAT: Es el "índice" del disco; indica al SO en qué clústeres está guardado cada archivo.
  • • Directorio raíz: Primera carpeta de la jerarquía (C:\ o /). Tiene tamaño fijo y guarda metadatos (nombre, tamaño, fecha...).
  • • Área de datos: Zona más grande del disco donde se guardan los archivos y subcarpetas.

3 Particiones de disco

Consiste en dividir el disco en partes asignando tamaño y estructura a cada una para que el SO pueda trabajar. Hay 3 tipos:

1. Primaria

Máximo 4 por disco. Es donde se instala habitualmente el Sistema Operativo.

2. Extendida

Máximo 1 por disco. Sirve como contenedor para meter dentro particiones lógicas.

3. Lógica

Ocupa una parte o toda la partición extendida. Permite tener muchas divisiones extra.

💡 Importante (Partición Activa y Arranque): Solo puede haber una partición activa en el disco (la primera que se lee al encender el PC). Para elegir qué SO arrancar si tenemos varios instalados, se usan gestores de arranque como bootmgr, boot.ini, GRUB, LILO, GAC o BootMagic.

Tema 5 (Continuación): El Sistema de Archivos

1 Concepto de Sistema de Archivos (File System)

  • • Estructura y organiza la información guardada en una unidad, controlando qué sectores están libres u ocupados.
  • • Se define durante el formateo del disco.
  • • Compatibilidad: Normalmente no son compatibles entre sí (ej. desde Windows con NTFS no puedes leer nativamente un disco Linux con EXT2, aunque Linux/UNIX sí suele poder leer FAT).

2 Características, Extensiones y Atributos de Archivos

  • • Longitud de nombres: En DOS máximo 8 caracteres; en Windows hasta 256 caracteres.
  • • Mayúsculas/Minúsculas: UNIX/Linux sí diferencia entre mayúsculas y minúsculas; Windows/DOS no.
  • • Extensiones comunes: Indican el tipo de archivo y con qué programa abrirlo:
    .EXE / .COM (Ejecutable) .BAT (Proceso por lotes DOS) .DLL (Librería dinámica) .DRV (Driver hardware) .SCR (Salvapantallas) .LNK (Acceso directo) .INI (Configuración) .CAB / .ZIP / .RAR (Comprimido) .OBJ (Código objeto C) .TMP (Temporal)
  • • Atributos principales de los archivos:
    Sólo lectura Se puede leer, pero no modificar.
    Oculto No se muestra visiblemente.
    Archivo Indica que ha sido modificado.
    Sistema Pertenece al SO (no al usuario).

3 Clasificación de los Sistemas de Archivos

De Disco
  • Microsoft: FAT16, FAT32, NTFS (más rápido y seguro que FAT).
  • Linux / UNIX: ext2, ext3, ext4, UNIX S5.
De Red
  • SMB: Samba.
  • NSS: Novell NetWare.
Propósito General
  • CDFS: Para unidades CD-ROM.
  • SWAP: Memoria de intercambio en Linux.
